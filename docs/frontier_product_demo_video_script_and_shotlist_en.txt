TrustLayer - Product Demo Video Script + Shot List (90 seconds)

Format:
- Voiceover: what you say
- Screen: what you record

00:00-00:08 | Intro
Voiceover:
"This is TrustLayer, a real-time Solana token risk intelligence app."
Screen:
- Start on homepage with full layout visible (top tokens table + analyzer + right panel).

00:08-00:18 | Header Options
Voiceover:
"In the header, Methodology opens our scoring logic and risk factors, while API opens live service health for operational transparency."
Screen:
- Move cursor to header buttons.
- Click Methodology, keep it open for 2 seconds, then close.
- Click API to open /health in a new tab, show JSON briefly, then return to app tab.

00:18-00:32 | Top Tokens Overview + Map
Voiceover:
"On the left, we track top Solana tokens with live market context and risk indicators, and we visualize market structure with a Liquidity vs Holder Concentration map."
Screen:
- Slowly move through Top Tokens table.
- Hover 2-3 rows to show row highlight behavior.
- Scroll to the insights section and open the Liquidity vs Holder Concentration map.
- Hover a few points on the map.

00:32-00:46 | Instant Token Analysis
Voiceover:
"You can analyze by token name or mint address. TrustLayer returns an explainable risk score with confidence."
Screen:
- In analyzer input, type a token name and select from suggestions.
- Let auto-analysis run and wait for right panel result.

00:46-01:00 | Explainability
Voiceover:
"Each result shows why the score was assigned: holder concentration, authority controls, liquidity, activity, metadata, and RPC diagnostics."
Screen:
- Keep right panel in focus.
- Scroll just enough to show risk breakdown, confidence, and warnings.

01:00-01:12 | Watchlist + Alerts
Voiceover:
"Users can add tokens to a watchlist, set risk-change thresholds, and receive alert updates when conditions shift."
Screen:
- Click favorite star for current token.
- Open Watchlist collapse.
- Change threshold and press Check Now.

01:12-01:24 | Recent Alerts + Compare
Voiceover:
"Recent Alerts gives a quick event feed, while Compare helps evaluate two tokens side by side."
Screen:
- Open Recent Alerts collapse briefly.
- Open Compare collapse and show Token A vs Token B summary.

01:24-01:30 | Close
Voiceover:
"TrustLayer helps traders make faster, safer token decisions with transparent risk context on Solana."
Screen:
- Return to top of right panel.
- Hold steady on a clean final frame (logo/header + selected token result).

Recording Notes:
- Record at 1080p, 30fps.
- Keep cursor movement slow and intentional.
- Pause one second after each click.
- Use one clean take first, then only re-record sections if needed.
